## Description
This project explores global air quality using the WHO Ambient Air Quality Database. Using R, we use our EDA that we carried out in Assessment 0 and further literary research to identify models relevant to pm10 concentration prediction. In our introduction we outline our goals and summarise any important EDA that led to our conclusion. 
We created an artificial competition environment where we each competed to create the best model to predict pm10_concentration, using data from cities in Europe (we justify our choice in our intro), which we then test on an out of sample validation set.

Throughout this project, we demonstrated the ability to:

- Clean and explore complex environmental datasets, identifying missingness patterns and applying appropriate preprocessing techniques.
- Develop and implement predictive models using a variety of machine learning models to predict PM10 concentrations across European cities.
- Optimise model performance through hyperparameter tuning and k-fold cross-validation, ensuring robust model selection and generalisable results.
- Evaluate and compare models using relevant key performance metrics, interpreting their relevance within a real-world air pollution context.
- Visualise results effectively, to show clearly actual vs predicted values pm10 concentration.

Our conclusions can be found in the 'Conclusion.Rmd' file.
